# Importa Aí 🚀

Sistema de Gestão e Rastreamento de Encomendas Internacionais (China → Brasil)

## Projeto Integrador — ADS 4º Período — PUC Goiás 2026/1

### Stack
- **Backend:** Java 17 + Spring Boot 3.x + RabbitMQ
- **Frontend:** React 18 + Tailwind CSS + WebSocket (STOMP)
- **Banco:** MySQL 8.x
- **Infra:** Docker Compose

### Estrutura do Repositório
- `/artefatos` — Documentação acadêmica por disciplina
- `/backend` — API REST + Consumidores RabbitMQ
- `/frontend` — Interface React
- `/infra` — Docker Compose + configurações de ambiente
